# Repository cleanup review — 2026-11-13

This pass scans application TypeScript for unused declarations and debug logging, checks exact duplicate styles, and reviews shared authentication, permissions, HTTP and report pagination. It does not certify every live business workflow.

## Changes

- Replaced 98 repeated authentication/JSON header blocks in AdminService and BranchService with `service/http-options.ts`. Headers read the current session and omit Authorization when no token exists.
- Fixed and registered the unused authentication interceptor. It previously cloned a request but sent the original. Authentication now applies to configured API URLs; external URLs and explicit Authorization headers remain untouched. Multipart content types remain browser-controlled.
- Fixed malformed report endpoint keys containing `/?/`, which never matched real service URLs. This restores report pagination and consolidated delivery-detail merging. Invalid or repeated pagination fails instead of looping or silently truncating results. Raw list consumers support arrays and data envelopes.
- Honor explicit staff permissions, including an empty list, before applying legacy defaults. Removed duplicated role migration/version assignments, an unused token cache and company-login flag.
- Prevent duplicate login submissions and handle network errors without dereferencing a missing error body.
- Added `shared/stored-report.ts` for four report screens. Missing or corrupt cached JSON no longer crashes those initializers. Removed repeated offline-report initialization.
- Moved nine identical SCSS sets from 30 components into `src/styles/components/`. Component entry points retain Angular encapsulation. Compiled Sass output matches the original Git version for all 30 consumers.
- Organized imports in 57 files with TypeScript's language service. Removed the empty ServiceService, its unused import/test, an accidentally committed Git-output file, and obsolete commented implementations in reviewed services/reports.
- Removed 767 standalone debug logs from 96 application files, plus shared profile/header response logging. Log arguments that invoke functions were preserved to avoid removing potential side effects. Warning/error handling remains. Confirmed no removed log expression was an unbraced control-flow body.
- Normalized generic BranchService API helpers against the shared base URL. Existing public methods, route URLs and business-screen folders remain compatible.

## Structure

- `service/`: authentication, permissions, HTTP options/interceptors and report page merging.

- Existing `Branch/`, `SubAdmin/`, `empolyee/`, `USER/` and `logistics/` folders retain their business screens. No broad folder rename was needed for this cleanup.
